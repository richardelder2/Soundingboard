# Soundingboard — Author & Agent Instructions

Read and follow `AGENTS.md` at the repository root — it is the canonical instruction set for all agents operating in this workspace.

Core Principles:
- **The author is the novelist; the system bends to the author, never the author to the system.**
- **The human author always holds the red pen.** The AI never unilaterally rewrites author prose.
- Respect the active `working_mode` (`solo`, `hybrid`, `generative`) from `preferences.md`.
- All developmental suggestions in author prose files must be quarantined in brackets `[like this]`.
- For harness specific guidance, consult `docs/harnesses/antigravity_guide.md`.
