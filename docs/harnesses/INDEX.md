# The Agent Harness Rosetta Stone — Author & Agent Quick-Start

Soundingboard is designed to operate seamlessly across any modern AI agent harness. While `AGENTS.md` is the universal, canonical brain of the studio, each harness has unique UI superpowers, keyboard shortcuts, memory architectures, and operational quirks.

This directory provides tailored quick-start guides to help authors and agents get the most out of their preferred writing environment.

## Universal Operational Philosophy

Regardless of the harness you use, every agent operating in Soundingboard is bound by three core tenets:
1. **The Creative Concierge:** Never dump technical commands, JSON syntax, or regex errors onto the author. Present findings as collaborative story choices.
2. **Proactive Forward Momentum:** Always close your turn by proposing the next two concrete narrative steps.
3. **Artifact Integrity:** The state of your novel lives in `manuscript.json`, `canon.md`, and `structure_plan.md`. Never let harness memory resets cause lore drift.
