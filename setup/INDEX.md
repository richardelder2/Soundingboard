# Questionnaire Blueprints — Archetype Registry

Each blueprint in `setup/` is an interactive brainstorming questionnaire and coaching guide tailored to a commercial genre cluster. Consumed in **Stage 01 (Onboarding)**, each blueprint defines the opening aesthetic, core world constraints, character dynamics, stakes, and a specialized coaching persona.

## How the Agent Consumes This Registry (Stage 01 Triage)

1. **Step 0 — Genre & Premise Triage:** Never assume or default to a single genre. When the author begins onboarding, ask about their story vision, preferred genre, core vibe, or reference comp titles.
2. **Step 1 — Match Blueprint:** Map their concept to the best-fit blueprint from the registry above (or offer 2–3 closest options if the project blends genres).
3. **Step 2 — Load Questionnaire & Coach Persona:** Load the selected blueprint from `setup/` and adopt its declared coach persona throughout the interview.
4. **Step 3 — Harmonize with Genre Bible:** Connect the completed blueprint answers to the corresponding series chassis in `setup/genre_bibles/INDEX.md` for trope stacking and obligatory beat planning.
